#  DecodeLabs Data Analytics Internship (Batch 2026)

This repository contains the projects I completed during my **DecodeLabs Data Analytics Internship (Batch 2026)**. The projects demonstrate an end-to-end data analytics workflow using an e-commerce dataset, covering data cleaning, exploratory data analysis, SQL-based querying, and business-focused data visualization.


##  Projects

### 🔹 Project 1 – Data Cleaning & Preparation
- Cleaned and validated raw e-commerce data
- Handled missing values and duplicate records
- Standardized data types and text fields
- Generated the cleaned dataset for further analysis

### 🔹 Project 2 – Exploratory Data Analysis (EDA)
- Performed descriptive statistical analysis
- Identified trends, distributions, and outliers
- Conducted correlation analysis
- Created statistical visualizations

### 🔹 Project 3 – SQL Data Analysis
- Answered business questions using SQL
- Applied aggregate functions, `GROUP BY`, `HAVING`, and subqueries
- Analyzed sales, products, payment methods, and referral sources

### 🔹 Project 4 – Data Visualization & Business Insights
- Built business-focused visualizations using Python
- Analyzed product performance, revenue, customer behavior, and monthly trends
- Created an interactive HTML dashboard to present key insights
