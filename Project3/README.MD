## Project 3: SQL Data Analysis

### Overview

This project uses SQL to analyze the cleaned e-commerce dataset stored in a relational database. The objective is to answer key business questions through SQL queries while demonstrating essential database querying skills used in real-world data analysis.

### Key Tasks

* Calculated total orders, total revenue, and average order value using aggregate functions.
* Identified high-value orders by filtering transactions based on **TotalPrice**.
* Analyzed product popularity using **GROUP BY** and **COUNT**.
* Examined customer payment preferences and order status distribution.
* Evaluated referral sources to understand customer acquisition channels.
* Used **HAVING** to identify products exceeding a specified order threshold.
* Calculated percentage contributions of payment methods and order statuses using subqueries.
* Compared average order values across referral sources to identify higher-value customer channels.

### Result

The SQL analysis produced results consistent with the Python-based EDA, confirming the accuracy of the cleaned dataset. The queries provided valuable insights into sales performance, customer behavior, payment preferences, and referral channel effectiveness.

### Key Takeaway

SQL is a fundamental tool for data analysis, enabling efficient data retrieval, aggregation, and filtering directly from databases. Mastering concepts such as **GROUP BY**, **HAVING**, and subqueries allows analysts to transform raw data into meaningful business insights.
