## Project 4: Data Visualization & Business Insights Reporting

### Overview

This project transforms the cleaned e-commerce dataset into clear and informative visualizations that communicate key business insights. Building on the previous projects, it presents analytical findings in a format that is easy for stakeholders to interpret and use for decision-making.

### Key Tasks

* Created bar charts to visualize **product popularity** and **revenue by product**.
* Generated a pie chart showing the distribution of **payment methods**.
* Visualized **order status** and **referral source** distributions using count plots.
* Used a boxplot and histogram to examine the distribution of **Total Price** and identify outliers.
* Created a correlation heatmap to highlight relationships between numeric variables.
* Plotted monthly order trends to analyze changes in order volume over time.
* Saved all visualizations as high-quality PNG files for reporting and presentation.

### Result

The project generated a collection of business-focused visualizations, including product performance, customer payment preferences, referral channels, revenue contribution, order trends, and statistical distributions. All charts were exported to the **Project4_Charts** folder, making them ready for presentations, reports, or dashboards.

### Key Takeaway

Data visualization transforms analytical results into clear, actionable insights. Well-designed charts make it easier to identify trends, compare performance, detect anomalies, and communicate findings effectively to both technical and non-technical audiences.
